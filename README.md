# KiranaSportHub_StrukturData
Kirana Sport Hub adalah sebuah web berbasis array, pointer, dan struct untuk mengelola data produk, keranjang, dan transaksi. Proses sorting dan searching ditampilkan transparan melalui log langkah demi langkah. Fitur keranjang, checkout, dan struk memperlihatkan implementasi struktur data tersebut secara nyata.
